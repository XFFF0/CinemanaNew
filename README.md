# Cinemana New

iOS client for Cinemana/Shabakaty streaming platform.

**Bundle ID:** `com.shabakaty.cinemananew`

## Features
- Browse featured & new releases
- Search movies and series
- Stream videos in multiple qualities
- Episode list for series

## API
Based on reverse-engineering of `cinemana-5-3-3.apk`.  
Base URL: `https://cinemana.shabakaty.com/api/android/`

## Build
GitHub Actions builds an unsigned IPA automatically on push.
Download from the Actions → Artifacts tab.

## Sideload
Use AltStore, SideStore, or Sideloadly to install the IPA.
